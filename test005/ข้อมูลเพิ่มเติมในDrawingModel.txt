
    public void undo() {
        if (!undoStack.isEmpty()) {
            // เก็บสถานะปัจจุบันลง Redo ก่อนเปลี่ยนไปใช้สถานะเก่า
            redoStack.push(cloneLayers(layers));
            
            // ดึงสถานะล่าสุดจาก Undo Stack กลับมาใช้งาน
            layers = undoStack.pop();
            
            // ปรับ activeLayerIndex ไม่ให้เกินขอบเขต
            if (activeLayerIndex >= layers.size()) {
                activeLayerIndex = layers.size() - 1;
            }
        }
    }

    ***ทำไมต้อง ปรับ activeLayerIndex ไม่ให้เกินขอบเขต***

    สาเหตุที่ต้องตรวจสอบและปรับ `activeLayerIndex` มีไว้เพื่อ **ป้องกันไม่ให้โปรแกรมพังด้วยข้อผิดพลาด `IndexOutOfBoundsException**` เมื่อจำนวนเลเยอร์ในอดีตลดน้อยลงกว่าเดิมครับ

---

### ลองดูสถานการณ์ตัวอย่าง (Scenario)

สมมติว่าผู้ใช้ทำตามลำดับขั้นตอนดังนี้:

1. **สร้างเลเยอร์เพิ่ม:** ตอนแรกโปรแกรมมี 1 เลเยอร์ จากนั้นผู้ใช้กดเพิ่มเลเยอร์ใหม่จนมีทั้งหมด **3 เลเยอร์** (Index 0, 1, 2)
2. **เลือกเลเยอร์บนสุด:** ผู้ใช้เลือกทำงานที่เลเยอร์ล่าสุด ทำให้ `activeLayerIndex = 2`
3. **กด Undo:** ผู้ใช้กด Undo ถอยหลังกลับไปในตอนที่มีเพียง **1 เลเยอร์** (Index 0)

---

### เกิดอะไรขึ้นถ้าไม่มีโค้ดส่วนนี้?

* ตัวแปร `layers` จะถูกดึงค่าย้อนกลับไปตอนที่มีเพียง **1 เลเยอร์** (`layers.size() == 1`)
* แต่ตัวแปร `activeLayerIndex` ยังคงค้างอยู่ที่ค่าเดิมคือ **`2`**
* เมื่อโปรแกรมพยายามสั่งวาดภาพหรือวาดเส้นลงบนเลเยอร์ปัจจุบันด้วยคำสั่ง:
```java
Layer currentLayer = layers.get(activeLayerIndex); // เท่ากับ layers.get(2)

```


* **ผลลัพธ์:** โปรแกรมจะพังทันทีเพราะพยายามเข้าถึงตำแหน่ง Index 2 ใน List ที่มีสมาชิกเพียงตำแหน่งเดียว (Index 0) และโยนข้อผิดพลาด **`IndexOutOfBoundsException`** ออกมา

---

### โค้ดนี้ช่วยแก้ไขอย่างไร?

```java
if (activeLayerIndex >= layers.size()) {
    activeLayerIndex = layers.size() - 1;
}

```

* โค้ดส่วนนี้จะเช็กว่า หาก index เลเยอร์ที่เลือกอยู่เดิม (`2`) มีค่า **มากกว่าหรือเท่ากับ** จำนวนเลเยอร์ที่มีอยู่จริงในปัจจุบัน (`1`)
* ให้ **รีเซ็ตตำแหน่งกลับมาอยู่ที่เลเยอร์บนสุดที่มีอยู่จริง** ทันที ซึ่งก็คือ `layers.size() - 1` (ในที่นี้คือ `1 - 1 = 0`)
* ทำให้โปรแกรมสามารถย้อนสถานะได้อย่างปลอดภัย โดยที่ตัวชี้เลเยอร์ไม่ "ลอย" เกินขอบเขตของข้อมูลครับ
