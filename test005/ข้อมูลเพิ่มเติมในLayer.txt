java.awt.Graphics g = imgCopy.getGraphics(); ทำอะไร

คำสั่ง `java.awt.Graphics g = imgCopy.getGraphics();` ทำหน้าที่ **สร้าง "พู่กัน/ผู้ช่วยวาดภาพ" (`Graphics`) เพื่อใช้วาดสิ่งต่างๆ 
ลงไปบนรูปภาพ `imgCopy` โดยตรง** (แทนการวาดลงบนหน้าจอ)

---

### เปรียบเทียบให้เห็นภาพง่ายๆ

* **`imgCopy`** = **ผืนผ้าใบเปล่า** (ภาพ `BufferedImage` ที่อยู่ในหน่วยความจำ)
* **`imgCopy.getGraphics()`** = **การหยิบพู่กันขึ้นมา** เพื่อเตรียมเขียนหรือวาดสิ่งต่างๆ ลงบนผืนผ้าใบ `imgCopy` นั้น

---

### นำไปใช้ทำอะไรในโปรแกรม Paint?

1. **การคัดลอก/สำเนาภาพ (Off-screen Drawing):**
เมื่อต้องการคัดลอกรูปภาพเดิมลงในรูปภาพใหม่ (`imgCopy`) เราจะสร้าง Graphics ของภาพใหม่ขึ้นมา แล้วสั่งวาดภาพเก่าลงไป:
```java
g.drawImage(oldImage, 0, 0, null); // วาดภาพเก่าลงบน imgCopy

```


2. **การบันทึกไฟล์ภาพ (Exporting to PNG/JPG):**
วาดวัตถุทั้งหมด (เลเยอร์, รูปทรง, ข้อความ) ลงบนตัวแปร `imgCopy` ในหน่วยความจำก่อน จากนั้นค่อยนำ `imgCopy` ไปเซฟลงดิสก์ด้วย `ImageIO.write()`

3. **กฎสำคัญเมื่อใช้งานเสร็จ (`g.dispose()`):**
เมื่อวาดภาพลงบน `imgCopy` เสร็จเรียบร้อยแล้ว **ต้องสั่ง `g.dispose();` เสมอ** เพื่อคืนหน่วยความจำและทรัพยากรของระบบปฏิบัติการ (Graphics Context) ทันที

```java
java.awt.Graphics g = imgCopy.getGraphics();
try {
    g.drawImage(originalImage, 0, 0, null); // วาดภาพ
} finally {
    g.dispose(); // คืนทรัพยากรเมื่อใช้วาดเสร็จ
}

```
