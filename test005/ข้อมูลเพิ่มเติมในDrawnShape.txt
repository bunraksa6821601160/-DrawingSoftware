###  `implements Serializable` คืออะไร มาจากไหน

* **มาจากไหน:** มาจาก `java.io.Serializable` (เป็น Interface ของภาษา Java standard library)
* **คืออะไร:** มันคือ **"Marker Interface"** (อินเทอร์เฟซเปล่าที่ไม่มีเมธอดใดๆ) ที่ใส่ไว้เพื่อแปะป้ายบอก Java ว่า 
**"คลาสนี้อนุญาตให้แปลงเป็น Byte Stream ได้นะ"**

* **นำไปใช้ทำอะไร:**
* เมื่อวัตถุ (Object) ถูกแปลงเป็นไฟล์ลงฮาร์ดดิสก์ (เช่น การทำเมนู **Save File / Save Project**)
* หรือถูกส่งผ่านเครือข่าย Network
* กระบวนการนี้เรียกว่า **Serialization** (การแปลง Object เป็นไฟล์) และ **Deserialization** (การอ่านไฟล์กลับมาเป็น Object)



> **สรุป:** ถ้าไม่ใส่ `implements Serializable` เวลาสั่ง `ObjectOutputStream.writeObject(shape)` เพื่อบันทึกงานลงไฟล์ 
โปรแกรมจะโยนข้อผิดพลาด `NotSerializableException` ทันที

enum คืออะไร

**enum** (ย่อมาจาก **Enumeration**) คือประเภทข้อมูลพิเศษในภาษาการเขียนโปรแกรม (เช่น Java, C#, C++, Python) ที่ใช้สำหรับกำหนด 
**"กลุ่มของค่าคงที่ที่แน่นอนและไม่เปลี่ยนแปลง"**

ลองคิดภาพว่า enum คือการทำ **รายการตัวเลือกแบบล็อคช้อยส์** เพื่อป้องกันไม่ให้โปรแกรมรับค่าที่ผิดพลาดเข้ามา

### หลักการคำนวณเบื้องหลังของ `bounds.contains(p)`

สมมติว่าสี่เหลี่ยม `bounds` มีพิกัดขอบเขตดังนี้:

* พิกัดมุมซ้ายบนคือ $(x, y)$
* ความกว้างคือ $w$ (width)
* ความสูงคือ $h$ (height)

เมื่อเราส่งจุด $p$ ที่มีพิกัด $(px, py)$ เข้าไป เมธอด `contains` จะเช็กเงื่อนไข 4 ข้อนี้พร้อมกัน:

1. $px \ge x$ (อยู่ทางขวาหรือทับขอบซ้าย)
2. $px < x + w$ (ไม่อยู่เลยขอบขวา)
3. $py \ge y$ (อยู่ล่างหรือทับขอบบน)
4. $py < y + h$ (ไม่อยู่เลยขอบล่าง)

* **ถ้าจริงครบทั้ง 4 ข้อ:** คืนค่า **`true`** (คลิกโดนวัตถุ)
* **ถ้ามีข้อใดข้อหนึ่งเป็นเท็จ:** คืนค่า **`false`** (คลิกไม่โดน)

### นำไปใช้ประโยชน์อะไรได้บ้าง?

1. **Hit Testing (การตรวจจับการคลิก):** ใช้เช็กว่าผู้ใช้เอาเมาส์ไปคลิกโดนข้อความ ปุ่ม หรือรูปทรงนั้นๆ หรือไม่
2. **Rubberband Selection (การลากเมาส์คลุมวัตถุ):** ใช้เช็กว่าวัตถุชิ้นไหนบ้างที่อยู่ในพื้นที่สี่เหลี่ยมที่เราลากเมาส์ครอบไว้
3. **Collision Detection (การชนกันในเกม):** เช็กว่าตัวละครหรือกระสุนสี่เหลี่ยมเดินไปชนขอบเขตของฉากหรือไม่
