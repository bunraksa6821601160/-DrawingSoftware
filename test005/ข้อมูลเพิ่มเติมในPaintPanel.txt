อย่าพึ่งรีบอ่าน Constructor อ่านพวก Function ก่อน

g2d.scale(zoom, zoom); ทำอะไร
g2d.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON); ทำอะไร

คำสั่งทั้งสองตัวนี้ทำหน้าที่ตั้งค่าการแสดงผลของระบบวาดภาพ Java 2D ดังนี้ครับ

---

### 1. `g2d.scale(zoom, zoom);`

คำสั่งนี้ใช้สำหรับ **การย่อ-ขยายสเกลระบบพิกัด (Coordinate Scaling)** ทั้งแกน X และแกน Y ตามค่าอัตราซูมที่กำหนด

* **หลักการทำงาน:** เป็นการปรับขนาดของสเกลการวาดล่วงหน้า ส่งผลให้ทุกอย่างที่ถูกวาดหลังจากบรรทัดนี้ (เส้น, สี่เหลี่ยม, ข้อความ, ภาพ) ขยายหรือย่อขนาดตามทันที
* **ตัวอย่างค่า `zoom`:**
* `zoom = 2.0` : ขยายขนาดการวาดขึ้นเป็น **200% (2 เท่า)**
* `zoom = 0.5` : ย่อขนาดการวาดลงเหลือ **50% (ครึ่งเดียว)**
* `zoom = 1.0` : ขนาดปกติ **100%**


* **ประโยชน์ในโปรแกรม Paint:** ช่วยให้เราสร้างระบบ Zoom In / Zoom Out ได้ง่ายๆ โดยไม่ต้องไปไล่คำนวณปรับพิกัดและขนาดของรูปทรงทุกชิ้นด้วยตัวเอง

---

### 2. `g2d.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON);`

คำสั่งนี้ใช้สำหรับ **เปิดใช้งานระบบลบขอบรอยหยัก (Anti-Aliasing)** ของเส้นและรูปทรงที่กำลังจะวาด

* **หลักการทำงาน:** โดยปกติเมื่อวาดเส้นโค้งหรือเส้นเฉียงบนจอภาพที่เป็นพิกเซลสี่เหลี่ยม จะเกิดรอยหยักแบบขั้นบันได (Jaggies) คำสั่งนี้จะสั่งให้ Java นำเทคนิค **Blending (ผสมสีส่วนขอบ)** มาใช้ โดยสร้างพิกเซลสีจางๆ บริเวณขอบเส้น
* **ผลลัพธ์ที่ได้:** เส้นวาด ข้อความ และขอบของรูปทรงจะดู **นุ่มนวล เรียบเนียน และสมจริงขึ้นมาก** ไม่ดูเป็นรอยหยักหยาบๆ
